# Super admin

Control plane for agencies. Runs on port 3004.

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

- Login: http://localhost:3004/super-admin/login
- Dashboard: http://localhost:3004/super-admin/dashboard

Uses this app's `.env.local` only. Super-admin email/password live in the **backend** `.env`.
